## Convention de lecture

- **Statut** indique si l'objet a déjà atteint son état cible ou attend un lot du
  backlog — pour ne pas coder contre une fiche déjà obsolète.
- **Composant référent** est le seul composant à modifier pour cet objet. Si vous
  vous apprêtez à en créer un second, relisez le principe 3 avant de continuer.
